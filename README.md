# page-web-data
mini-projet page web avec données en table

On donne une démo (dans le dossier demo) :
- *table1.csv*
- *table1_moyennes_pageWeb.py*
- *moyenne.html*

Le fichier *moyenne.html* est produit par le programme Python.

Dans le programme Python, on lit le fichier *table1.csv*. Les données sont mises dans une liste de dictionnaires Python.
Puis on produit le fichier HTML, avec une moyenne des notes calculées affichées dans un tableau.

On demande de vous inspirer de la démonstration afin :
- de récupérer un fichier csv dans le domaine qui vous intéresse (« open data » comme mot-clé vous donnera déjà pas mal de ressources). Plus il y a de lignes, plus c'est intéressant... ;
- éventuellement de « nettoyer » ces données dans libreoffice ;
- de prévoir un petit traitement pertinent en Python de ces données (un total, un comptage, une moyenne, etc.) ;
- de restituer **une partie** des enregistrements (avec un filtre, vous n'allez pas afficher une page de 10 000 lignes quand même !) et leur traitement.
